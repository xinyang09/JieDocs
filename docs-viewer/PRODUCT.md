# 文档台

## Register
Product：现有 React 文档工作台，不是宣传网站。

## Purpose
面向 FNS Vault 用户，阅读、搜索和编辑同步笔记。XDB 页面应呈现配置定义的真实视图，而非配置字段清单。

空间管理已上线：侧栏底部的空间切换器支持新建空间。空间对应 FNS 的 Vault，名称必填且最多 255 个字符；创建通过 WebGUI 认证的 `POST /api/vault` 完成，成功后自动切换并读取新空间的空目录。重名、权限错误和网络错误会保留当前空间并提示错误；空间删除和回滚继续由服务端 Vault 管理接口负责。

## Design

独立云同步（实验中，2026-10-17）：Web 文档台和 macOS 客户端使用同一套 docs UI；`docs-module/` 提供独立的本地 Markdown 核心，`desktop-client/` 在本地模式下使用当前空间根目录作为工作目录，并通过电脑本地智能体执行 AI 对话，也可以选择其它本地文件夹；同一份 `docs-viewer` 构建产物通过 preload 访问本地或云端 API，不加载远程 `/docs/` 页面，交互方向参考 Flowix。云同步只是同步功能，开启后才启用 session/device/batch 和同步设备面板，用于把本地 Vault 同步到云端并让其它客户端读取同一云端 Vault，不限制搜索、任务、预览、AI、设置等其它 docs 能力。桌面、移动客户端可直接调用 `/api/sync/sessions` 创建会话、读取持久化快照/差异批次，也可连接 `/api/sync/ws` 使用 `CloudSyncPull` 批次拉取，并通过 `/api/sync/sessions/{sessionId}/operations` 提交带 CAS 的单项 Markdown、`.obsidian` 配置或目录创建。同步冲突保留远端内容并返回 409，目录重命名继续使用既有目录接口，附件正文必须先使用现有文件与分片接口上传。设备摘要、重命名和撤销接口使用服务端版本校验且不回显令牌。本地 Vault 与云端后台双向合并、附件镜像、实时推送、后台监控和多文档原子事务仍待实现。
文档台参考 scaffold-master 的珍珠玻璃设计：灰白舞台和深色圆角外框组织导航与工作区，文字导航按功能分组，支持收起为图标；顶栏、目录、阅读面、首页和共享控件使用统一边框、圆角、阴影与蓝色强调。首次使用默认浅色，保留已有用户的主题选择；深色沿用同一布局，小屏使用紧凑底部导航与目录抽屉。导航收起状态仅保留在当前页面。沿用已有认证、Vault 权限、数据 API、错误反馈及写入冲突处理，原 Markdown、Frontmatter、换行和 Unicode 处理不变。回退前端版本即可撤销此界面调整。

2026-10-13 前端改造已实现，生产构建和 129 项前端测试通过；使用只读测试 Vault 检查明暗主题、首页、文档阅读、任务视图、AI 对话、设置及导航收起，并验证 1440px 桌面、1024px 平板和 390px／375px 手机布局。优先级看板允许横向滚动，手机任务页全宽显示，新增任务入口独立成行。构建产物已同步至 `frontend/docs` 并比对一致；尚未在真实服务上回归数据写入，Go 内嵌版需重新编译、重启后生效。

标题浮动显示（2026-10-15）：桌面端打开 Markdown 文档后，大纲标题收回为阅读区右侧的窄浮动入口，悬停或键盘聚焦时展开标题列表，点击标题仍使用原有客户端滚动跳转；中屏和窄屏继续隐藏大纲。沿用当前 Vault 文档读取权限、Markdown 标题解析与读取错误提示，不新增 API、数据写入、并发冲突或权限边界；恢复 `src/pearl-theme.css` 的前端样式即可回滚。已通过生产构建、Markdown 大纲测试和 macOS ARM64 Go 内嵌服务重编译；当前浏览器在刷新后令牌过期，未读取或修改账号凭据，真实文档数据态仍待有效会话回归。

沿用现有明暗主题、紧凑工具栏和附件区域。XDB 的 parentId、rootGroup 与布局是页面结构依据；小屏允许重排。禁止伪造统计数据，不执行远程配置中的任意脚本。未知语法与加载错误明确显示。

目录、搜索、收藏、最近访问和首页最近文档列表在名称旁显示独立的小矩形文件类型标签：笔记显示 MD，附件按扩展名显示大写类型，无扩展名显示 FILE；列表条目名称不重复显示后缀文件名扩展名，类型完全由独立标签展示，悬停时保留完整路径查看。沿用已有 Vault 读取权限与列表 API，仅改变展示，不改名、不写入文档或持久化数据，无新增并发写入；回退前端即可撤销。2026-10-09 前端已更新并构建通过，本地 /docs/ 返回 200。

Office 文件通过 Univer 查看、编辑并保存：`.doc/.docx` 使用文档导入导出，`.xls/.xlsx/.xlsm/.csv/.tsv` 使用表格导入导出，`.ppt/.pptx` 使用幻灯片导入导出。Go 服务调用 `docs-viewer/server/univer-exchange.mjs` 和 `@univerjs-pro/exchange-node`，接口为 `/api/file/univer` 与 `/api/file/univer/export`，沿用 Vault 读取权限和文件写入校验；转换失败不覆盖原文件。DOCX 编辑器的 `/` 斜杠命令菜单在 Univer Rendered 生命周期后订阅，并使用完整 renderer 计算 viewport 锚点；保留画布逻辑尺寸和段落原始坐标。2026-10-14 已重新编译并重启本地 Go 内嵌服务，在实际 `123.docx` 页面验证刷新后及 100%／80% 缩放下菜单显示在输入行下方。运行环境需要 Node.js >=22.5、`docs-viewer` 依赖和可执行脚本，launchd 可通过 `PATH` 或 `FNS_NODE_BIN` 指定 Node。发行包未内置 Node、脚本或 native binding，Linux armv7 等无对应 binding 的平台不保证支持；已验证中文 DOCX 导入 smoke、后端 Univer 单测、前端 133 项测试和生产构建（含 4 项生命周期回归测试）。

Markdown 题头图存储在 Frontmatter 的 `cover`、`coverImage` 或 `image` 字段中，图片上传到当前文档目录或引用网络图片，并在标题上方全宽渲染。编辑器支持本地添加、随机网络获取、更换和移除；本地图片更换时先上传新附件再以文档版本校验保存，随机网络图片依赖外部服务，移除只清除 Frontmatter 引用。

文件、Markdown 文档和目录可像 Notion 一样从文档阅读器标题旁直接添加或更换表情；带题头图的 Markdown 文档会把同一表情显示在题头图下沿左侧。也可从“更多操作”设置、替换或清除单个 Unicode 表情图标，并在目录树、文件列表和文档导航中一致展示。选择器默认展示全部图标，另按常用、表情、人物、自然、食物、活动、物品、地点和符号分类，支持中文名称搜索与自定义粘贴；网格有滚动上限以保持弹窗紧凑。图标使用 `localStorage` 保存，按 Vault、资源类型和规范化路径隔离，是当前浏览器的显示偏好；不写入 Markdown Frontmatter、二进制附件、服务端数据库或 API，也不随 Vault 跨浏览器或设备同步。文件与目录仍沿用原有权限，重命名和移动时迁移本地图标；清除可恢复默认图标，值无效或本地存储失败时保留原显示并提示。

## AI 模型入口
系统设置中的“AI 模型服务”允许用户添加 OpenAI 兼容接口或 Ollama，模型选择器只展示服务摘要和模型 ID。API Key 只提交给 FNS 服务端保存，不写入浏览器本地存储或对话历史；未配置自定义服务时仍可使用 Pi 兼容执行器。macOS 桌面端本地模式将模型目录显示为“本地智能体”，由本机 Pi 兼容命令在当前工作空间 `cwd` 中执行，不把工作目录或文档内容发送到 FNS 云端。桌面端“智能体设置”会自动扫描本机 PATH、显式智能体命令和 Mirasim 安装目录，显示检测结果并允许选择已支持的 Pi 命令；目录切换会同步更新智能体工作目录。 AI 对话的模型选择与刷新统一从输入框旁的模型选择弹窗进入，顶部不再显示重复的“模型／自动模型／刷新列表”工具栏。2026-10-15 已通过相关 7 项测试、生产构建和实际页面检查，模型加载与选择继续沿用原接口。右侧引用来源面板移除重复的“最近回答来源”标题和匹配摘要，仅保留引用数量摘要与文档列表。
