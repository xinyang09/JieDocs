# 文档台

Web 文档工作台，用于浏览和编辑 Fast Note Sync Service 中的 Vault 与 Markdown 笔记，并提供内嵌 `sheet` 表格的编辑、公式、选区、复制粘贴和保存能力。

内嵌 Markdown `sheet` 表格和直接上传或同步的 `.doc`、`.docx`、`.xls`、`.xlsx`、`.xlsm`、`.csv`、`.tsv`、`.ppt`、`.pptx` 文件使用 Univer 查看、编辑并保存回 Office 格式；`.pdf` 可直接查看，`.ods`、`.odt`、`.odp` 仍使用 LibreOffice 转 PDF 预览。

## 界面风格

界面参考 scaffold-master 的 Pearl Glass 设计，采用珍珠灰背景、深色圆角外框、分组主导航和蓝色操作按钮。点击品牌右侧的按钮可收起主导航；平板自动显示图标导航，手机使用底部导航和目录抽屉。首次使用默认浅色，已保存的浅色、深色或系统主题偏好继续生效。

统一主题变量和响应式样式位于 `src/pearl-theme.css`，在原样式之后加载；导航收起状态仅保留在当前页面。文档、任务、模型配置与权限检查继续使用原有流程。构建命令为 `npm run build`，前端回归测试可运行 `node --experimental-strip-types --test tests/*.test.ts`。Go 内嵌版需将 `dist` 内容同步到仓库根目录的 `frontend/docs`，再重新编译、重启 Go 服务。

桌面端 Markdown 阅读器的大纲标题以右侧浮动入口呈现，悬停或键盘聚焦时展开；中屏和窄屏隐藏大纲，文档内容继续在阅读区内部滚动。

## Office 编辑依赖

Univer 的浏览器编辑器负责交互，Go 服务通过 `docs-viewer/server/univer-exchange.mjs` 调用 `@univerjs-pro/exchange-node` 完成 Office 文件导入和导出。DOCX 中输入 `/` 打开的斜杠命令菜单在 Univer Rendered 生命周期后订阅，由文档台用完整 renderer 计算 viewport 锚点；同时保留画布逻辑尺寸和段落原始坐标，避免服务未注册时修正失效或污染段落布局。2026-10-14 已通过 133 项前端测试和生产构建，重新编译并重启本地 Go 内嵌服务，在实际 `123.docx` 页面检查刷新后及 100%／80% 缩放下菜单贴近输入行。部署 Go 内嵌版时需要在服务运行环境安装 Node.js（>=22.5）并在 `docs-viewer` 目录执行 `npm install`；也可以通过 `FNS_UNIVER_EXCHANGE_SCRIPT` 指定转换脚本的绝对路径，或通过 `FNS_NODE_BIN` 指定 Node 可执行文件的绝对路径。若服务由 launchd 启动，需将 Node 所在目录加入 `PATH`。PDF 不经过 Univer，继续使用现有 PDF 查看器。

## 启动

```bash
npm install
npm run dev
```

打开终端显示的地址，通常为 `http://localhost:4173`。首次进入需要使用 FNS 账号登录。在登录页填写：

- FNS 用户名或邮箱
- FNS 用户密码

浏览器使用当前页面的同源 API。开发与预览服务器的 FNS 上游按 `FNS_BASE_URL`、`VITE_FNS_BASE_URL`、`http://127.0.0.1:9000` 的顺序解析；本机运行可在 `.env.local` 中设置 `VITE_FNS_BASE_URL=http://127.0.0.1:9000`。每次打开页面会验证已保存的登录状态，退出登录或会话失效后会清除本地凭据并重新要求登录，不保存登录密码。

## 跨域

`npm run dev` 和 `npm run preview` 将 `/api/*` HTTP 与 WebSocket 请求转发到上述 FNS 上游，保留请求体、认证头及后端状态码，因此登录不依赖浏览器 CORS。API 路径不会经过旧本地会话代理，后端继续校验账号、令牌与 Vault 权限。Go 内嵌部署直接使用同源 FNS 接口；单独使用 `npm start` 时仍需额外反向代理 `/api/*` 到 FNS，不能仅靠旧 `/fns-proxy` 路径。生产部署使用 HTTPS。

## AI 助手

AI 对话输入框右侧的麦克风按钮支持中文语音输入：点击开始，再次点击结束，识别完成后追加到草稿，需手动确认发送。每次最长识别约 60 秒；切换对话或离开页面会取消本次识别。浏览器需要支持 `SpeechRecognition` / `webkitSpeechRecognition` 并获准访问麦克风，使用 HTTPS 或本机地址；部分内嵌浏览器可能不支持。浏览器可能通过在线语音服务处理音频。页面不会自动发送消息，项目不保存音频文件；不支持或连接失败时可使用系统听写。

打开一篇 Markdown 笔记后，选中文本即可使用浮动 AI 工具条进行提问、改写、精简或翻译；改写类结果会先以预览形式展示，确认后只替换选区，也可以复制或关闭。点击标题栏的 ✨ 按钮仍可打开完整笔记助手，执行摘要、润色、创建文档等指令。整篇文档修改同样先生成修改建议，接受后才会写入，并支持追加到文末、放弃和撤销。模型请求由 FNS 服务端执行，浏览器不会保存或接触 API Key。

流式失败会保留已有回答并显示模型服务的安全错误原因。接口返回 400 且明确拒绝模型时，请核对 AI 模型设置中的模型 ID；服务不会自动切换为其他模型。真实断流仍提示未完成，不能作为成功回答。

### 自定义模型 API

编辑已保存的模型服务时会自动发现可用模型，也可以点击“刷新模型”。从目录点击模型 ID 后保存服务，即可更新默认模型；发现不会自动覆盖配置，未保存的地址、协议或密钥不参与请求。AI 对话输入框旁的模型菜单也使用真实目录。目录由服务端持有凭据读取，不会把 API Key 发回浏览器。

在系统设置的“AI 模型服务”中添加服务，填写名称、API 地址、默认模型和 API Key。首个协议支持 OpenAI 兼容的 Chat Completions 接口，地址通常填到 `/v1`（服务端会补上 `/chat/completions`）；Ollama 可填写兼容接口地址。保存后模型会出现在 AI 对话和选区助手的模型选择器中，也可以使用“测试连接”检查服务。

API Key 只提交到 FNS 服务端，由独立的 `.ai.key` 文件保护的 AES-GCM 密文保存（可用 `FNS_AI_KEY_FILE` 指定密钥文件）；列表和模型选择只返回服务摘要，不回显密钥。更新时 API Key 留空会保留原密钥，修改服务地址时需要重新填写密钥。服务配置按用户隔离，配置权限使用 `config_r/config_w`。

自定义服务配置完成后，AI 执行不需要安装 Pi。没有可用自定义服务时，平台仍会尝试使用 Pi 兼容执行器；Pi 模型是可选回退，不影响笔记同步、文件和 Vault 功能。出于安全原因，服务端默认拒绝本机或私有网络地址；管理员明确设置 `FNS_AI_ALLOW_PRIVATE_ENDPOINTS=true` 后才可连接本地 Ollama。

若使用 Pi 兼容回退，先按 [Pi 官方说明](https://pi.dev/) 安装并完成模型提供商登录或 API Key 配置；默认要求 `pi` 在 `PATH` 中。若使用自定义路径，可在启动文档台前设置 `PI_BIN`。自定义模型 API 不需要 Pi：

```bash
PI_BIN=/absolute/path/to/pi npm start
```

AI 结果先显示在对话框中，确认后才能复制或替换整篇文档。

### AI 对话模型切换

独立 AI 对话页顶部的“模型”下拉框可切换当前对话使用的模型。选择“自动模型”时使用已启用自定义服务的默认模型，没有配置时回退服务端 Pi；显式选择模型时，下次发送或重新生成会使用所选模型，已有回复不会改变。每段对话分别保存选择，新对话沿用最近一次选择，刷新后保留。

Go 内嵌版和 Node 文档台均提供 `GET /api/ai/models`，返回已启用自定义服务的模型摘要，并在可用时附加 Pi 本机模型；不会返回密钥。配置新增模型后点击“刷新列表”；列表为空或不可用时会显示提示，不会静默换成其他模型。右侧引用来源面板仅保留引用数量摘要和文档列表，移除重复的“最近回答来源”标题及匹配摘要。生成期间禁止切换。

旧的 `POST /pi-ai` 和 `GET /pi-models` 仅用于兼容迁移。新的客户端统一使用 `/api/ai/execute`、`/api/ai/models` 和 `/api/ai/providers`；部署 Go 内嵌版时须更新 `frontend/docs` 构建产物并重新编译、重启 Go 服务。

## 2FA 验证码

登录文档台后，从左侧导航打开“2FA 验证码”即可保存 Base32 设置密钥或完整的 `otpauth://totp/` 链接，并查看、复制自动刷新的动态验证码。密钥不会返回到前端或写入普通笔记，而是使用服务端单独的 AES-256-GCM 密钥加密后保存；默认密钥文件为配置文件同目录的 `.twofa.key`，也可以通过 `FNS_TWOFA_KEY_FILE` 指定路径。请将该文件限制为服务进程可读（权限 `0600`），并纳入安全备份；丢失后无法解密已保存的 2FA 账户。
# XDB 配置预览

打开远程附件列表或搜索结果中的 `.xdb` 文件，可查看字段、视图名称和类型，并展开完整 JSON 配置。扩展名不区分大小写。

此版本仅提供只读配置预览，不会查询配置中的数据源、执行脚本或按钮，也不会还原表格、日历、统计或甘特图。支持不超过 5 MB、包含 `fields` 和 `views` 对象数组的 JSON 文件；原文件不会被修改。
