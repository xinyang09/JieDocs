# Markdown 排版润色技能 (Markdown Polisher)

当用户要求对文档进行排版、优化结构、调整层级或润色语言时，严格遵循以下规范：

## 1. 规范排版
- 中文与英文、数字之间保持一个半角空格（例如：`使用 React 19 框架`）。
- 专有名词保持官方大小写规范（如 `GitHub`、`TypeScript`、`Obsidian`、`API`）。
- 统一使用规范标点，中文语境下使用全角标点符号。

## 2. 结构清晰
- 保持标题层级清晰（`#` -> `##` -> `###`），避免跳级。
- 关键概念与重点操作使用列表与加粗高亮展示。
- 表格数据保持对齐，代码块必须标注明确的语言标识符（如 ````ts`、````bash`）。
