DEVELOPER FIRST

      
写给开发者的接口。

      
MCP 与 REST 双通道，一个 token 即可接上你的自动化。

    


    

      

        
        
        
        JSON / YAML
      

      

        
{"mcpServers": {"fns": {"url": "http://host:9000/api/mcp","type": "http","headers": {"Authorization": "Bearer <token>"}}}}

        
curl -X POST http://host:9000/api/note \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"title":"hello","content":"# 你好，世界"}'

        
const ws = new WebSocket("ws://host:9000/api/user/sync?token=<token>");
ws.onmessage = (e) => render(JSON.parse(e.data));

FAQ

      
你可能想问的。

    

    

      

        和 iCloud / 云笔记有什么区别？
        
FNS 是你自己部署的同步层：数据留在你的服务器，走 WebSocket 毫秒级推送，还额外提供 MCP / REST API 让 AI 和脚本直接读写。开源、可控、可审计。

      

      

        我需要什么数据库？
        
默认 SQLite 零配置起步即可；数据量上来后可无缝切换到 MySQL 或 PostgreSQL，满足团队级部署。

      

      

        离线的时候改笔记会丢吗？
        
不会。支持离线编辑自动合并，重新联网后离线改动与删除会自动解决（需在客户端插件开启对应策略）。

      

      

        自托管安全吗？
        
开源可审计，支持 OIDC 登录与 token 鉴权；服务只在你自己的机器上，数据不外流。社区也提供 Nginx 反向代理示例。
